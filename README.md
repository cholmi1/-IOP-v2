# 안압케어 IOP v2

녹내장 환자의 안압 측정·기록·추세 분석에 특화된 **안압관리 전용** 애플리케이션입니다. C&V Tech의 안압계 **CVT200**과 연동되며, 하나의 코드베이스에서 **환자 앱**과 **의료진 웹** 두 가지 화면을 제공합니다.

기존 통합앱(안압 + 점안 + 문진 + 건강)에서 안압관리 모듈만 분리해 단독 제품으로 재구성한 버전입니다.

---

## 주요 기능

### 환자 앱

| 화면 | 내용 |
|---|---|
| **로그인** | 개별 회원가입 · SNS 로그인(카카오·네이버 / Google·Apple·Facebook / WeChat·Weibo·QQ) · 비회원 사용 |
| **홈** | 좌·우안 안압 게이지, 오늘 요약(평균·일중 변동폭·목표 초과), 측정 알림 배너, 대여 기기 반납 알림 |
| **측정** | 우안 / 좌안 / 양안 **선택 측정**, 자동(CVT200)·수동 입력, 측정 상황 태그, 측정 스케줄 진행 상태 |
| **기록** | 기간별 분석과 **그래프 형식 선택**(Chart · Scatter · Diurnal), 일중 변동폭, 시간대별 프로파일 |
| **설정** | 목표 안압, 측정 알림 시간, 푸시 알림, 기기 등록·반납 관리, 의료진 공유 동의 |

### 의료진 웹

| 메뉴 | 내용 |
|---|---|
| **로그인** | 기관 계정 로그인, 우상단 프로필 메뉴(프로필 · 비밀번호 변경 · 로그아웃) |
| **환자 (고객 DB)** | 이름·ID·성별·연락처·가입 경로·기기 구분·기기 상태 전 컬럼 정렬, 검색·필터, 신규 등록 |
| **환자 상세** | 측정 결과(그래프 3종 + 이력), 기기 관리, 환자 프로필, 인증·사용 기간 |
| **장치** | 병원 대여용 / 개인 소유 / 원내용 구분 관리, 대여·반납·연체 추적 |
| **알림 자동화** | 반납 알림 스케줄러, 단계별 발송 채널 설정, 발송 감사 로그 |
| **사용자 / 권한** | 직원 계정 관리(관리자 전용), 역할별 권한 매트릭스 |

## 핵심 설계

### 1. 좌·우안 선택 측정

한쪽 눈만 측정한 기록도 그대로 저장되며, 양안 선택 시 우안 → 좌안 순서로 진행됩니다. 측정하지 않은 눈은 게이지에 "측정 기록 없음"으로 표시됩니다.

### 2. 그래프 형식 선택

| 형식 | 표현 | 용도 |
|---|---|---|
| **Chart** | 날짜별 평균 라인 + 일중 최소~최대 밴드 | 장기 추세 파악 |
| **Scatter** | 개별 측정값을 점으로 표시 | 분포와 이상치 확인 |
| **Diurnal** | 0~24시 축에 겹쳐 표시, 야간 구간 음영 | 하루 중 안압 리듬 확인 |

여기에 양안 / 우안 / 좌안 필터를 조합할 수 있습니다.

### 3. 기기 소유 형태 이원화

| 구분 | 병원 대여 | 개인 소유 |
|---|---|---|
| 자산 | 기관 소유, 기간 대여 | 환자가 직접 구입 |
| 관리 항목 | 대여 시작일 · 반납 예정일 | 연동일 |
| 종료 처리 | 반납 처리 → 대여 가능 상태 복귀 | 연동 해제 |

### 4. 반납 알림 자동화

```
D-3 안내 → D-1 알림 → 당일 알림 → 연체 경고 → 유예 초과 시 데이터 수신 중단
```

단계별로 앱 푸시 · SMS · 유선 안내 채널을 조합할 수 있고, 모든 발송은 자동/수동 구분과 처리자를 남기는 감사 로그에 기록됩니다. 수신 중단 상태에서도 환자 앱의 로컬 저장은 유지되며, 반납·연장 시 미전송 데이터가 일괄 재전송됩니다.

## 기술 스택

- **React 18** + **Vite 5**
- **Recharts** — 안압 추세·산점도·일중 변동 차트
- **lucide-react** — 아이콘
- **Tailwind CSS** (CDN) — 레이아웃 유틸리티

현재 버전은 프런트엔드 프로토타입으로, 모든 데이터가 클라이언트 상태로 관리됩니다. 백엔드 연동 시 필요한 서버 측 명세는 [`docs/notify-integration-spec.md`](docs/notify-integration-spec.md)를 참고하세요.
